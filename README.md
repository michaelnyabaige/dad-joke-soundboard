# 🥁 Dad Joke Soundboard

An interactive, feature-rich web application built to bring dad jokes to life with sound pads, custom voice recording, and meme poster generation.

🚀 **Live Demo:** https://zoophagous-copper-5bstpvtx.edgeone.dev/

---

## ✨ Features

* **Interactive Sound Pads:** Play classic reaction sounds powered by Howler.js.
* **Custom Audio Recording:** Record your own sound bites saved directly via IndexedDB.
* **Dad Voice (TTS):** Hear fetched dad jokes read aloud using the Web Speech API.
* **Meme Generator:** Export custom joke cards as downloadable PNG images.
* **Groan-o-Meter & Particle Effects:** React to jokes with animated visual feedback.
* **Keyboard Navigation:** Full hotkey support (`1`–`9`, `Space`, `Enter`).

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **Libraries:** Howler.js, Canvas Confetti, html2canvas
* **Storage:** IndexedDB, localStorage
